# 🏗️ Backend Architecture & Engineering

<div align="center">

```text
                 Client / Frontend
                         |
                         v
                    API Gateway
                         |
             +-----------+-----------+
             |           |           |
             v           v           v
        Plan Service Customer Service Order Service
             |           |           |
             v           v           v
           Redis     Oracle/MySQL  Database
             |
             v
        Cached Responses

      Microservices Communication
                         |
                         v
                    Apache Kafka
                         |
                         v
                  Event Consumers

        Logs • Metrics • Monitoring
```

</div>

### Architecture Concepts

- **API Gateway:** Central entry point for routing and request handling.
- **Microservices:** Separates application capabilities into independently maintained services.
- **Kafka:** Supports asynchronous messaging and event-driven communication.
- **Redis:** Caches frequently accessed data to reduce repeated database reads.
- **SQL Databases:** Store persistent application and business data.
- **Testing:** JUnit and Mockito for unit testing; Swagger/OpenAPI for API documentation.
- **Delivery:** Git, Maven, Jenkins, Docker, Kubernetes, and CI/CD tools.
